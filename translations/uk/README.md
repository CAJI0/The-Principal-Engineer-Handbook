# Ukrainian Translation Workstream

This directory contains the Ukrainian translation workstream for The Principal Engineer Handbook.

The immutable English source baseline is `v1.0.0`. Canonical English manuscript content remains in `book/` and must not be modified by Ukrainian translation phases unless maintainers explicitly approve a separate English-source change.

Future Ukrainian translated source will live under `translations/uk/book/`. This strategy registration phase does not create translated chapters or copy source chapters into that directory.

Ukrainian publishing configuration, Ukrainian web navigation, and Ukrainian PDF export support will be added separately after translated source files exist.

Translation work must preserve the book structure and all PEAK concept IDs, chapter IDs, artifact IDs, law IDs, smell IDs, metric IDs, ritual IDs, and failure IDs.
