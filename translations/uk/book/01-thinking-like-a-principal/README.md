# Мислити як Principal

Ця частина закладає спосіб мислення Principal Engineer: рішення як майбутня вартість системи, обмеження як частина судження, питання як інженерний інструмент, ownership як відповідальність за bounded outcome, докази як межа впевненості, а stewardship як звичка залишати наступну зміну дешевшою, безпечнішою або зрозумілішою.
