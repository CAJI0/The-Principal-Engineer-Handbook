# Побудова продукту

Частина IV переводить архітектурне мислення з внутрішнього дизайну в продуктову реальність: прототипи, виробництво, польові умови, конфігурації, варіанти, спостережуваність, випуски та оновлення. Тут рішення мають витримувати не лише інженерний стенд, а й людей, інструменти, пристрої та процедури, які працюватимуть без команди прототипу поруч.
